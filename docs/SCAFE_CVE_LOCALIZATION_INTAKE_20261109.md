## Admission and inspection boundary

Before any localization value inspection, a fixed salted case-ID rule allocated
491 IDs to 295 development and 196 provisional reserve cases. Reserve locations,
summaries, snippets and target values were not inspected. This is not a qualified
independent split: multiple CVEs may share deployments, projects or source clones,
and historical overlap is unresolved. Grouping must precede any frozen evaluation.

The bounded intake acquired 405,294 bytes of original localization annotations and
two schemas, with exact advertised sizes/Git blobs and SHA256 receipts. It also
pinned licensing, provenance and targeted catalog metadata. A recursive catalog
hit its 4 MiB cap; its partial response was preserved unparsed, then replaced by
small nonrecursive catalog lookups. No cap increase or archive expansion occurred.
No downloaded dataset script, installer, source code or model was executed.

The localization JSON unexpectedly also contains source snippets. The mixed raw
file is quarantined; its embedded source is not covered by the authors' grant.
The delivered working projection excludes source_text, descriptions, summaries,
statements and other narrative fields. It retains factual source pointers and
function coordinates only. Future intake must inspect schemas before data-file
acquisition and separate mixed third-party fields before any downstream use.
No report bodies, CVE record files, taxonomy corpora or model weights were fetched.

## Measured development coverage

The 295 development cases yield 303 coordinate records, all with valid ordered
positive line ranges. They contain 300 distinct artifact/source/contract/signature/
line keys, referring to 283 artifacts and only 54 distinct signature strings.
There are 300 function records and three fallback records. These are not 300
independently unique functions or projects; repeated signatures flag a grouping
risk, not a measured clone rate. No three-category target was inferred from a
location or an unmentioned function, and no negative label was manufactured.
The source describes reviewed locations for CVE claims while explicitly declining
to independently verify every vulnerability claim. That distinction is retained.
