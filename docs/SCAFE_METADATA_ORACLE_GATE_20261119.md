`scripts/audit_structural_oracle_metadata.py` rejects unrequested/source-bearing fields, duplicate or invalid IDs and wrong contract identities; missing ID/build fields stay unknown. It always keeps metadata evidence separate from an AST oracle and source admission. Twelve controls cover those boundaries and exact compiler-commit comparison. Dictionary fixtures are software tests, not generated research examples.
