# SCAFE accelerated evidence decision — 8 November 2026

## Outcome first

A few-week submission-ready evidence package is a conditional target, **not a
credible commitment on current evidence**. There is no qualified independent
SCAFE evaluation cohort or new model-performance gain. Two Q1-level acceptances
cannot be promised; journal review is separate from preparing a defensible paper.
This plan has an early stop/pivot checkpoint, not an open-ended curation program.
No architecture, feature recipe, model, dataset or old paper framing is mandatory.

The first candidate question is: within real audited source files, can cheap
function/context information improve recovery of **audit-reported finding
locations** at a fixed analyst budget beyond matched length/name/rule baselines?
Reported-finding retrieval is distinct from proven vulnerability detection.
Unmentioned functions are unlabeled, not safe negatives. Existing three-category
labels and prior results are not relabeled into this new target. This is a
candidate design, not an established contribution or completed ranking experiment.

## Smallest decisive experiment completed

Before the new mapping count, the session fixed provisional screening floors of
30 uniquely span/line-anchored functions across 10 project groups. These are
feasibility floors, not power calculations or data-admission permission. The
retained CoinFabrik frame has 171 source finding records, 331 vulnerable-function
candidates and 15 projects. Using existing exact-context/symbol/span/line checks
without category harmonization yields only 10 consistent finding links involving
**8 functions in 4 projects**. Only 52 candidates have exact qualified context
spans. There are 83 producer-linked references with unavailable exact context and
two with missing/ambiguous native pointer/anchor correspondence.

Decision: **stop the current retained pilot as a method benchmark**. Do not fit an
encoder or report a ranking result on these eight functions. No canonical labels,
independent gold, training/evaluation eligibility or splits were created. The link
checks concern retained source claims, not independent semantic adjudication.
Full candidate-universe completeness and separate qualified evaluation remain
prerequisites. Previously inspected sources cannot become fresh confirmation.

source/version, terms, provenance, task/label, leakage, size/disk and resource
checks. This session retrieved only the official pinned CoinFabrik LICENSE,
README and recursive tree metadata: 2,332,499 bytes, no contract source or archive.
The pin is `efd709441987a28bd7220d79b2d872f8c7cfa8d9`; LICENSE/README SHA-256 match

trust, credential or security-setting change, no insecure TLS option or code execution.

The catalog identifies 17 missing files across eight projects, totaling 165,688

terms. Unknown or incompatible evidence is excluded, not guessed. Future retrieval
must match the pin, API size and original retained context SHA-256, record time and
hashes, preserve originals, and never execute downloaded code. Old CF remains
exploratory/development; a separate qualified confirmation cohort is still needed.
No new software, model download, paid resource or private upload is authorized.

The 5-point/budget rule is a prospective development decision, not a result or a
promise of statistical power. Exact budget universe, protocol and adequate sample

that protocol before outcomes, not moving thresholds after seeing them.

## Keep the two papers substantively distinct

The saved data-centric manuscript abstract concerns contract-level label cleaning,
annotation/acquisition budgets, pruning and difficulty ordering under fixed models,
with grouping limitations disclosed. SCAFE's candidate is a function/context triage
method with budgeted reported-location recovery. Do not reuse its intervention
tables or claim its data-cleaning findings as SCAFE contributions. Shared background
or infrastructure must be disclosed. This is a coordination proposal based on the
current local abstract, not a change to the data-centric task or an agreement that
either direction is already publishable. Recheck separation if either pivots.

Localization/ranking is not novel merely because the target is function-level:
[ContractScanner](https://ieeexplore.ieee.org/document/11054301) already addresses
fine-grained localization; [SmartAuditFlow](https://arxiv.org/html/2505.15242v2)
uses ranking-related audit metrics. These primary references are positioning
checks, not matched numerical baselines or independently verified novelty claims.
The existing reference-to-gap review remains applicable for controls and limitations.
