\section{Smart Contracts}

Smart contracts are self-executing contracts with the terms of the agreement directly written into code. They run on blockchain platforms, most notably Ethereum, and automatically execute when predetermined conditions are met.

\subsection{Key Characteristics}

Smart contracts exhibit several important characteristics:

\begin{itemize}
    \item \textbf{Autonomy}: Once deployed, smart contracts operate independently without requiring intermediaries.
    \item \textbf{Immutability}: Once deployed to the blockchain, smart contract code cannot be easily modified, ensuring trust and predictability.
    \item \textbf{Transparency}: All transactions and contract states are publicly visible on the blockchain.
    \item \textbf{Decentralization}: Smart contracts run on distributed networks, eliminating single points of failure.
\end{itemize}

\subsection{Common Use Cases}

Smart contracts have found applications across various domains:

\begin{enumerate}
    \item \textbf{DeFi (Decentralized Finance)}: Automated lending, borrowing, and trading protocols that operate without traditional financial intermediaries.
    \item \textbf{NFTs (Non-Fungible Tokens)}: Unique digital assets representing ownership of digital or physical items.
    \item \textbf{Supply Chain Management}: Tracking goods and automating payments throughout the supply chain.
    \item \textbf{Governance}: Decentralized autonomous organizations (DAOs) use smart contracts for voting and decision-making.
\end{enumerate}

\subsection{Example: ERC-721 Token Contract}

A common example of a smart contract is the ERC-721 standard for NFTs. The following code snippet demonstrates a simplified version:

\begin{verbatim}
contract ERC721 {
    mapping(uint256 => address) private _owners;
    mapping(address => uint256) private _balances;
    
    function transferFrom(address from, address to, uint256 tokenId) public {
        require(_owners[tokenId] == from, "Not owner");
        _owners[tokenId] = to;
        _balances[from]--;
        _balances[to]++;
    }
}
\end{verbatim}

This contract implements a basic NFT transfer mechanism, where ownership of tokens is tracked through mappings and transfers are validated before execution.

As shown in Figure~\ref{fig:crypto_trend}, the cryptocurrency market has experienced several distinct phases:

\begin{itemize}
    \item \textbf{Early Growth (2015-2017)}: Initial adoption and rapid expansion, with market cap growing from \$5 billion to over \$600 billion.
    \item \textbf{Correction (2018-2019)}: Market correction following the 2017 peak, with values stabilizing around \$130-200 billion.
    \item \textbf{Institutional Adoption (2020-2021)}: Renewed interest from institutional investors drove market cap to over \$2.3 trillion.
    \item \textbf{Recent Volatility (2022-2024)}: Market experienced corrections but maintained higher baseline values, with continued growth in 2024.
\end{itemize}

This trend reflects the evolving nature of the cryptocurrency ecosystem, influenced by factors such as regulatory developments, technological advances, institutional adoption, and broader economic conditions.
